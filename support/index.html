SBS Maker Suite Support

SBS Maker Suite creates side-by-side video from separate left-eye and right-eye video files on macOS.

Basic workflow

  1. Select the left video and right video.
  2. Use Video Sync or Audio Sync, then review and adjust the frame offset if needed.
  3. Set the Start and End range.
  4. Adjust Vertical Align if needed.
  5. Select HSBS or FSBS, Fit or Fill, output size, and audio source.
  6. Choose an output destination and export.

Input and export notes

SBS Maker Suite is designed for compatible left/right source pairs. Some mismatched frame rates, HDR combinations, pixel aspect ratios, or unsupported timing may be rejected to preserve stereo timing and output integrity.

Common issues

  • If automatic sync is not reliable, use the frame-level manual sync review.
  • If the selected audio source has no audio track, select the other source or choose no audio.
  • If export cannot start at the requested size, choose a smaller output size supported by the Mac's HEVC Main 10 hardware encoder.

SBS Maker Suite サポート

SBS Maker Suiteは、別々の左眼動画・右眼動画からSide-by-Side動画を作成するmacOSアプリです。

基本手順

  1. 左動画と右動画を選択します。
  2. Video SyncまたはAudio Syncを実行し、必要に応じてフレーム単位で同期を調整します。
  3. 開始・終了範囲を指定します。
  4. 必要に応じて縦アラインを調整します。
  5. HSBS/FSBS、Fit/Fill、出力サイズ、音声を選択します。
  6. 出力先を選択して書き出します。

問い合わせ・不具合報告

サポート、不具合報告、フィードバックは公開Issueを利用できます。
